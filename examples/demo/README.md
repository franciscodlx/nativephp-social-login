# Demo de nativephp-social-login

App Laravel + NativePHP Mobile 4 con una pantalla nativa (`app/Native/SocialDemo.php`) que inicia sesión con los 10 proveedores del plugin. Sin client IDs en `.env`, cada proveedor usa los mocks de `tools/`.

Cómo correrla, con mocks o con cuentas reales: [CONTRIBUTING.md](../../CONTRIBUTING.md).
